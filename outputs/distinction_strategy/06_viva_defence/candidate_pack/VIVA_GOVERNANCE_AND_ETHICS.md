# Governance and ethics defence

## Defence position

The current artefact is a **research prototype and audit workflow**, not a production decision system.

## Policy risks of LLM use here

- Generated text can look authoritative.  
- Wrong-artefact extraction (procedural language).  
- Meaning alteration despite quote presence (faithfulness).  
- Misleading officials if candidates are accepted without human review.

## Required human oversight

- Rubric A/B (or equivalent) before journal acceptance.  
- Faithfulness check when summaries are used.  
- Framework mapping only after validated source.

## Logging / approval / access (deployment hypothetical)

Would need: immutable candidate log, reviewer identity, decision outcome, model/prompt version, access controls, retention policy. **Not implemented as production.**

## Sensitive inquiry evidence

- Prefer public Module 2 materials; do not commit restricted UKHSA correspondence; demo uses curated public quotes.

## Could it be deployed now?

**No.** Needs multi-reviewer validation, domain calibration, access governance, and explicit organisational acceptance criteria.

## Accountability support

Visible separation of source / machine / automated / human layers makes the route inspectable — supporting audit, not replacing judgement.
