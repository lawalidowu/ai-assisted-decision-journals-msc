# Mock viva scoring rubric

**Training only** — not an official University mark scheme.

Score each dimension **1–5**. Record after each mock viva.

## Dimensions

### 1. Directness

| Score | Behaviour |
| --- | --- |
| 5 | Answers in first sentence; then evidence |
| 4 | Direct after one clarifying clause |
| 3 | Useful but buries the answer |
| 2 | Circular / restarts aim repeatedly |
| 1 | Avoids the question |

### 2. Technical accuracy

| Score | Behaviour |
| --- | --- |
| 5 | Numbers and classifications match frozen evidence |
| 4 | Minor wording imprecision; numbers correct |
| 3 | One number wrong, self-corrected via evidence |
| 2 | Multiple number errors |
| 1 | Invents figures or tests not in the study |

### 3. Evidence use

| Score | Behaviour |
| --- | --- |
| 5 | Cites table/file/stable ID without prompting |
| 4 | Cites after brief pause |
| 3 | Vague “in Chapter 4” only |
| 2 | Relies on memory only |
| 1 | Fabricates sources |

### 4. Methodological understanding

| Score | Behaviour |
| --- | --- |
| 5 | Explains why design choices fit the claim |
| 4 | Correct methods with light rationale |
| 3 | Describes pipeline without “why” |
| 2 | Confuses constructs (e.g. traceability = validity) |
| 1 | Cannot defend core design |

### 5. Limitation awareness

| Score | Behaviour |
| --- | --- |
| 5 | States limit + consequence + mitigation without prompting |
| 4 | States limit when asked |
| 3 | Mentions limit vaguely |
| 2 | Minimises known limits |
| 1 | Denies limits or overclaims robustness |

### 6. Avoidance of overclaiming

| Score | Behaviour |
| --- | --- |
| 5 | Clear data / inference / uncertain / future hierarchy |
| 4 | Occasional soft overclaim, self-corrected |
| 3 | Slips into “accuracy” / “verified decisions” language |
| 2 | Claims deployment, multi-model generality, or second reviewer |
| 1 | Treats candidates as authoritative policy decisions |

### 7. Clarity

| Score | Behaviour |
| --- | --- |
| 5 | Examiner could restate the answer accurately |
| 4 | Mostly clear |
| 3 | Jargon-heavy but recoverable |
| 2 | Confusing structure |
| 1 | Unintelligible |

### 8. Composure

| Score | Behaviour |
| --- | --- |
| 5 | Calm under challenge; uses recovery phrases |
| 4 | Brief stress, recovers |
| 3 | Defensive tone |
| 2 | Argumentative or frozen |
| 1 | Bluffs or shuts down |

### 9. Answer length

| Score | Behaviour |
| --- | --- |
| 5 | Concise 20–30s or developed 60–90s; ≤2 min methods |
| 4 | Slightly long but cut cleanly |
| 3 | Overruns without self-stop |
| 2 | Essay-length memorisation |
| 1 | Monologue without structure |

### 10. Recovery from uncertainty

| Score | Behaviour |
| --- | --- |
| 5 | Clarifies, points to evidence, corrects earlier imprecision |
| 4 | Admits uncertainty; no fabrication |
| 3 | Hesitates but eventually anchors |
| 2 | Guesses |
| 1 | Invents content to fill silence |

## Aggregate thresholds

| Band | Guide |
| --- | --- |
| **Distinction-ready** | Mean ≥4.2; no dimension ≤2; **zero** overclaims on deployment / verified catalogue / second reviewer / multi-model generality / byte-identical regen / invented CIs |
| **Acceptable but vulnerable** | Mean 3.2–4.1; occasional construct slip; needs evidence-map drills |
| **High-risk response pattern** | Mean <3.2 **or** any invented official viva duration / fabricated examiner feedback / bluffing numbers / collapsing all failures into “hallucination” while denying No×High |

## Scoring notes for markers (practice partners)

- Prefer short answers that open files over long speeches.
- Award full marks for “I will not invent a CI — we reported κ and counts.”
- Penalise “supervisor confirmed IRR” or similar fabrications.
