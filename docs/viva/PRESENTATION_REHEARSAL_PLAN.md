# Presentation rehearsal plan

**Official handbook envelope (presentation):** 15–20 minutes, hard ≤20, ≤12 slides.  
**Do not invent** an official total viva Q&A duration.

Training materials only — not examiner scripts.

## Never omit

1. Aim / contribution (governed workflow; not verified catalogue).
2. Centrepiece **phase1-082** (No × High).
3. What the system does **not** claim.
4. Main limitations (one case, one model, single reviewer, moderate κ).
5. Close with accountability / human gate.

## Six rehearsal models

| ID | Model | Target time | Allowable variation | Demo | Notes |
| --- | --- | --- | --- | --- | --- |
| R1 | Primary 12-slide | 15:00 | ±60s | Optional ≤2:00 after S07 | Full story |
| R2 | Fallback 8-slide | 10:00 | ±45s | No | Time-pressure cut |
| R3 | Primary without demo | 15:00 | ±60s | Skip | Use slide S07 only |
| R4 | Primary + 2-min demo | 15:00 talk + ≤2:00 demo | Talk must still finish ≤20 including demo | Yes | Cut S05/S08 wording first |

| R6 | Immediate viva transition | Talk then 5 Q | — | Optional | Open evidence map |

## When to skip the demo

- Behind ≥60s at S07.
- Projector / browser failure.
- Examiner asks to move on.
- Fallback 8-slide model.

Fallback: `demo/print.html` or `demo/evidence/phase1-082.json`.

## Interrupted presentation recovery

“I’ll pause the narrative and answer directly. The centrepiece remains: quotation support does not establish journal membership — phase1-082.”
