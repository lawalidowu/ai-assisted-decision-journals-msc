## Core contribution (do not soften)

The work presents a **governed decision-journaling workflow** that visibly separates machine-generated candidates, automated traceability checks, human validation and authoritative source evidence.  
It is **not** an automatically verified policy catalogue.

## Six distinctions

1. Candidate generation  
2. Mechanical traceability  
3. Evidence strength (Rubric B)  
4. Semantic faithfulness  
5. Journal validity (Rubric A)  
6. Framework-based interpretation  

## Aim (exact — Ch1 §1.3)

To design and evaluate an LLM-assisted method for creating traceable candidate decision-journal entries from complex public records, using UK COVID-19 Inquiry Module 2 transcripts as a case study.

**Research questions:** Chapter 1 has **no numbered RQs**. Formal framing = Aim + Objectives 1–6.
