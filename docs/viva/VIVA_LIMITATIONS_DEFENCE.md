# Limitations defence

For each limitation: acknowledge → consequence → mitigation already used → proportionate future work.  
Do **not** claim limitations prove robustness.

## One UK COVID-19 Inquiry case study (eight hearings)

- **Consequence:** External validity untested.  
- **Mitigation:** Public, citable Module 2 corpus; explicit case-study framing (Ch1.4).  
- **Future:** Cross-inquiry replication.

## One main model

- **Consequence:** Results are model-conditioned; no model-independent claim.  
- **Mitigation:** Frozen historical outputs; contribution framed as workflow governance.  
- **Future:** Systematic multi-model comparison.

## Single-reviewer validation

- **Consequence:** No independent inter-rater reliability.  
- **Mitigation:** Explicit rubrics; stable IDs; frozen samples; moderate κ reported not hidden.  
- **Future:** Independent multi-reviewer study.  
- **Do not claim:** supervisor comments = second reviewer.

## Moderate agreement (κ 0.48 / 0.39)

- **Consequence:** Automated confidence cannot replace human Rubric B.  
- **Mitigation:** Reported exact agreement and weighted κ; linked to No × High pattern.  
- **Future:** Better confidence models + dual rating.

## Sample sizes (n=42 / 50 / 60)

- **Consequence:** Bounded feasibility, not population rates.  
- **Mitigation:** Stratification / purposive design stated; not over-generalised.  
- **Future:** Larger multi-site samples.

## Framework subjectivity (JEE / DQ)

- **Consequence:** Mappings are interpretive aids, not official WHO/DQ audits.  
- **Mitigation:** After source validation; warning on phase1-246; Audit E path lock.  
- **Future:** Multi-analyst mapping reliability.

## Frozen historical outputs / non-byte-identical regen

- **Consequence:** Live API regeneration may differ.  
- **Mitigation:** Fixed journal SHA; demo freeze banner; reproducibility limits documented.  
- **Future:** Versioned model snapshots under institutional governance.

## No deployment evaluation

- **Consequence:** Not a production system.  
- **Mitigation:** Explicit non-deployment claims throughout.  
- **Future:** Controlled access, logging, approval workflows.

## Public-transcript genre

- **Consequence:** Hearing discourse ≠ internal decision memos.  
- **Mitigation:** Operational journal definition distinguishes speech acts.  
- **Future:** Domain calibration on other record types.
